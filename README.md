# QuestTimes
A personal productivity &amp; habit tracker built with vibe coding style to conquer early mornings and daily goals. Crafted by Marshal
# 🗺️  Quest Times !!

> *"Bangun pagi bukan sekadar rutinitas, tapi awal dari sebuah petualangan baru."*

Aplikasi web *tracker* produktivitas dan kebiasaan (*habit tracker*) pribadi yang dibangun dengan gaya *vibe coding*. Proyek ini dirancang dengan **tema petualangan** untuk membuat proses membangun konsistensi harian (seperti bangun pagi) terasa seperti sebuah game RPG yang adiktif dan menyenangkan!

---

## ✨ Fitur Petualangan Utama

*   ⚔️ **Aktivitas & Misi Harian:** Tambahkan kebiasaan atau tugas harianmu (seperti bangun pagi jam 07:00 AM) layaknya misi petualangan yang harus diselesaikan.
*   🔥 **Sistem *Streak* Harian:** Lacak konsistensimu! Pertahankan rantai *streak* harianmu agar petualanganmu tidak terhenti.
*   ⏰ **Pengingat Pintار:** Alarm dan notifikasi agar kamu tidak pernah melewatkan waktu mulai misi harianmu.
*   🏆 **Sistem Gelar & Pangkat (Rank System):** Semakin konsisten kamu menyelesaikan misi, semakin tinggi gelar petualanganmu di dalam web:
    *   🤓**Petualang Pemula** (Baru memulai perjalanan)
    *   🧭 **Penjelajah** (Mulai terbiasa dan konsisten)
    *   🛡️ **Veteran** (Konsistensi tingkat tinggi)
    *   👑 **Legenda** (Master produktivitas sejati)

---

*   **Frontend:** HTML5, CSS, JavaScript (Vibe Coding Style)
